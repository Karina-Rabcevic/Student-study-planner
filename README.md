# Student-study-planner

## Описание проекта

Информационная система планирования учебного времени и перерывов студентов.

Проект представляет собой веб-приложение, предназначенное для организации самостоятельной учебной деятельности студентов, распределения учебной нагрузки и планирования перерывов.

## Основные функции системы

- Создание, просмотр, редактирование и удаление учебных задач.
- Указание сроков и продолжительности выполнения задач.
- Формирование плана учебной работы.
- Использование таймера учебных интервалов и перерывов.
- Настройка продолжительности учебных интервалов.
- Получение уведомлений о завершении интервала.
- Сохранение задач, планов и настроек пользователя.

## Техническое задание

Подробное описание требований к системе представлено в [лабораторной работе № 2](./lab2/).

## Планируемые технологии и архитектурные решения

- Веб-интерфейс (Frontend).
- Сервер приложения (Backend).
- PostgreSQL — предполагаемая система управления базами данных.
- REST API — взаимодействие клиентской и серверной частей.
- HTTP и JSON — передача данных.
- UML — моделирование структуры и поведения системы.
- ER-диаграммы — проектирование модели данных.
- Паттерн «Фасад» (Facade) — организация взаимодействия внутренних модулей.
- Git и GitHub — контроль версий проекта.

## Структура репозитория

- lab1/ — технико-экономическое обоснование.
- lab2/ — техническое задание.
- lab3/ — UML-диаграммы и проектирование системы.
- lab4/ — модель данных, архитектура и спецификация API.
- prototypes/ — прототипы пользовательского интерфейса.
- src/ — структура исходного кода.
- config/ — файлы конфигурации.
- docs/ — итоговый комплект документации (планируется).

- README.md — описание проекта.

## Предполагаемая инструкция по сборке и запуску

1. Клонировать репозиторий на локальный компьютер.
2. Подготовить среду разработки.
3. Установить необходимые зависимости.
4. Создать и настроить базу данных PostgreSQL.
5. Настроить параметры подключения к базе данных.
6. Запустить серверную часть приложения.
7. Запустить клиентскую часть приложения.
8. Открыть веб-приложение в браузере и проверить основные функции.

На текущем этапе проект находится на стадии проектирования. Инструкция по запуску будет уточняться после реализации программных модулей.

## Информация для разработчиков

Перед началом работы необходимо ознакомиться с техническим заданием, UML-диаграммами, моделью данных и спецификацией API.

Изменения рекомендуется выполнять в отдельных ветках репозитория. После завершения работы необходимо создать коммит с описанием изменений и оформить Pull Request для проверки и согласования.

Проект разрабатывается в рамках учебных лабораторных работ.
